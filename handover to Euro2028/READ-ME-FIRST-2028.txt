The one thing to hear before anything elseThis whole app was built for World Cup 2026: 48 teams, three groupphases, a specific knockout bracket, a 3rd-place playoff, and exact teamnames baked into the database.Euro 2028 is a different animal. Historically the Euros are 24 teams,6 groups of 4, best third-placed teams advancing, no 3rd-place playoff,and a different knockout progression. Confirm the exact Euro 2028 formatfirst — UEFA may have changed it (there's been talk of expanding).So set your expectations honestly: restarting for the Euros is closer to arebuild than a reboot. You are not just "changing the year and pressinggo." Rounds, team list, group structure, the bracket, and the scoring rulesall have to be reworked. It's very doable — you built it once — but it's aproject, not a click.---📦 BACKUP — read this before you panic about a missing databaseA full backup was taken on 20 July 2026. Every player, pick, match, and result liveshere. Project ID: `jrdjdqjepffdcjdfuarc`. You run SQL in its SQL editor.External data — The Odds API (betting odds) and football-data.org(live scores). The change loop (how an edit gets from laptop to live site)Open the repo folder in VS Code.Edit the file.Right-click the HTML → Open with Live Server → test it locally.Happy? Commit + push to GitHub (Source Control panel in VS Code, or`git add` / `git commit` / `git push`).Netlify auto-builds (~1–2 minutes). Watch it in the Netlify dashboard.Check the live site. Hard-refresh (Ctrl+Shift+R) to beat the cache.Golden rules you set yourself: never edit live, always test in Live Serverfirst, and batch changes to save Netlify build credits.---3.
